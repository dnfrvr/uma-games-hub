# Dress my Drew 🦅✨

Jeu de dress-up rétro façon 2012, où on habille Drew (avec un mauvais goût assumé)
et on peut exporter la tenue en PNG.

## Lancer le prototype
Aucune installation nécessaire : ouvrir `index.html` dans un navigateur, ou servir
le dossier avec un petit serveur local (recommandé pour que `fetch` charge bien
`assets/manifest.json`) :

```bash
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```
